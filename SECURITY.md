# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ColorCast, please report it
privately rather than opening a public issue.

**Email:** m.semoglou@tongji.edu.cn

Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Affected versions (e.g. 2.4.2, or a range)
- Any suggested mitigations

You will receive an acknowledgement within 5 business days. The issue
will be resolved before a public advisory or release is made.

## Supported Versions

The latest minor release series receives security fixes. Earlier minor
series are not supported.

| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |
